# 🎯 Python Number Guessing Game

A simple, interactive, and beginner-friendly command-line game built in Python where players guess a randomly generated secret number within a custom range.

---

## 🚀 Features

- **Custom Ranges**: Players set their own minimum and maximum bounds.
- **Input Validation**: Safely handles non-numeric inputs and out-of-bounds guesses without crashing.
- **Score Tracking**: Tracks total attempts made to guess the secret number.

---

## 🛠️ Requirements

- **Python 3.x** (no external libraries needed, uses built-in `random`).
